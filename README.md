# Nefas City — version PC (Windows)

Jeu cyberpunk en monde ouvert.

## ⬇️ [Télécharger Nefas City pour Windows](https://github.com/Adenera247/nefas-city-pc/releases/download/lanceur/NefasCity-Windows.zip)

1. Télécharge le fichier `.zip` ci-dessus et ouvre-le.
2. Double-clique sur **NefasCity.exe**.
3. Le jeu se télécharge puis se lance. **Les mises à jour s'installent toutes seules** à chaque lancement.

> **« Windows a protégé votre ordinateur » ?** C'est normal pour un jeu indépendant non signé :
> clique sur **Informations complémentaires**, puis **Exécuter quand même**.

Sans connexion internet, la dernière version installée démarre quand même.

---

Configuration conseillée : Windows 10/11 64 bits, carte graphique compatible Vulkan.
Le jeu est installé dans `%LOCALAPPDATA%\NefasCity` — pour le désinstaller, supprime ce dossier et `NefasCity.exe`.
